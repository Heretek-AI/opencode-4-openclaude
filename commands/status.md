Check the status of the Opencode Unlocked bridge and show connection health:
1. Query `http://127.0.0.1:8788/status` or execute `${CLAUDE_PLUGIN_ROOT}/bin/opencode-unlocked status`.
2. Report the active default model (Muse Spark 1.3 Contributor), upstream connectivity, and session request/token usage statistics.
